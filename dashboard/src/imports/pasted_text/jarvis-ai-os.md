Design a futuristic desktop web application called "JARVIS".

This is NOT a company dashboard.
This is NOT a CRM.
This is NOT a productivity template.

This is a Personal AI Operating System built specifically for one person.

The user is:
- Class 10 ICSE student
- Learning Python, AI and Full Stack Development
- Building real AI projects
- Wants to score 95%+ in boards
- Wants an elite physique

- Wants to earn money through technology
- Wants one application that manages every aspect of life.

The application should feel like opening Tony Stark's personal computer.
