# Score cinématique (optionnel)

Place ici un fichier **`score.mp3`** pour remplacer / renforcer la nappe
procédurale Matrix.

```
hud/public/boot/score.mp3
```

Le générique officiel de *The Matrix Reloaded* est **copyrighté** — on ne
peut pas le livrer dans le dépôt. Utilise un morceau libre de droits, ou
ta propre copie personnelle en local (non commitée).

Sans fichier : la nappe Web Audio (pluie digitale + basse pulse + stingers)
tourne seule.
